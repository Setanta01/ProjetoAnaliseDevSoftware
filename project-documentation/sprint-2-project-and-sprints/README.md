# Project and Sprint Management

Esta pasta concentra a documentacao nova para o trabalho de Sprint 2:
projetos, membros, sprints, backlog, cards, movimentacao, Planning Poker e
encerramento de ciclo.

## Documentos

- `SPRINT_2_SCOPE_AND_INTERPRETATION.md`: leitura consolidada do PDF de
  priorizacao em comparacao com fluxos, endpoints, arquitetura e schema.
- `PROJECT_AND_SPRINT_MANAGEMENT_IMPLEMENTATION_PLAN.md`: plano de implementacao
  com checklist, contratos esperados e perguntas abertas.

## Fontes de verdade

Para implementacao, siga a prioridade definida em `AGENTS.md`:

1. `project-documentation/fluxos_de_uso.md`
2. `project-documentation/Documento de Arquitetura de Software.md`
3. `project-documentation/endpoints-resumido.md`
4. `backend/api/migrations/sql/initial_schema.sql`
5. `project-documentation/Documento de Priorização.pdf` como priorizacao de
   escopo, nao como substituto dos contratos acima.
